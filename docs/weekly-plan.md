# Weekly plan

Each student gets one plan per week.

- Monday to Friday, one line per day: the subject and the exercise.
- - A plan is written by the tutor on Sunday and read by the student and a parent.
  - - When a day is done, the student ticks it; the tutor sees the ticks on Friday evening.
   
    - The plan page shows the current week first and the past weeks below it.
